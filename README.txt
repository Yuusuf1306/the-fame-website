THE FAME WEBSITE
=================

4-page responsive static website:
- index.html — Home
- services.html — Services
- products.html — Electrical Materials
- contact.html — Contact / quote form
- assets/logo.png — generated logo
- style.css — design
- script.js — mobile menu + WhatsApp enquiry

BEFORE PUBLISHING:
1. Replace the placeholder phone number and WhatsApp number in contact.html and script.js.
2. Replace the placeholder email/location.
3. Add real product photos and prices.
4. Confirm the exact services the client provides.
5. Add the client's social media links if needed.

The site is designed to be opened locally or uploaded to a normal web host.
